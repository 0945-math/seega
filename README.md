# 🏛️ シーガ (Seega) - 古代エジプトのボードゲーム

古代エジプトのボードゲーム「シーガ」を、AlphaGo風AIと対戦できるWebアプリケーションです。

## ゲームの特徴

- AlphaGo風AI（MCTS＋簡易ニューラルネットワーク）
- シーガのこのプロジェクト固有のルールを実装
- 挟み取りと連続キャプチャ
- ヒント、棋譜、統計、巻き戻し
- GitHub Pagesへの自動デプロイ

## クイックスタート

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

ビルド：

```bash
npm run build
```

型チェック：

```bash
npm run typecheck
```

## 構成

```
src/
├── game/
│   ├── seega.ts
│   └── mcts.ts

```

## AI

AIはモンテカルロ木探索を中心とし、盤面特徴からポリシーを生成する簡易ニューラルネットワークを探索の事前確率として利用します。

今回の修正版では、探索木で実戦側と同じ連続キャプチャ状態を扱えるようにし、MCTSの展開・シミュレーション・バックプロパゲーションを修正しています。

## 注意

このプロジェクトでは、一般的なシーガのルールを勝手に仕様へ置き換えず、プロジェクトで採用している固有ルールを正とします。
